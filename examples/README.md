# Worked example: one lead, end to end

These files show a single fictional lead at every stage of the workflow. They are generated by `node scripts/generate_examples.js`, which runs the workflow's own Code nodes. Only the website HTML and the LLM response are mocked; everything else is computed by the real logic.

| File | Stage | Produced by |
| --- | --- | --- |
| [`01-form-submission.json`](01-form-submission.json) | What the website form sends | Form |
| [`02-normalized-lead.json`](02-normalized-lead.json) | Cleaned fields, consent, language, region | Normalize & Validate |
| [`03-llm-request.json`](03-llm-request.json) | The full prompt sent to OpenAI | Prepare LLM Request |
| [`04-llm-response.json`](04-llm-response.json) | Structured facts plus fit judgment (mocked) | LLM Extract & Judge |
| [`05-scored-lead.json`](05-scored-lead.json) | Score breakdown, tier, owner, review flag | Score Lead |
| [`06-hubspot-payloads.json`](06-hubspot-payloads.json) | Company, contact and note bodies sent to HubSpot | Score Lead, Route & Compose |
| [`07-slack-message.json`](07-slack-message.json) | The Slack alert | Route & Compose |

Result: **83/100, Tier A**, routed to the DACH BDR.

"Muster Rechtsanwälte" is invented, and `muster-rechtsanwaelte.example` uses the reserved `.example` domain, which cannot belong to any real organisation.
